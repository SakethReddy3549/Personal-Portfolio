    Research Assistant

    Georgia State University

    • Built an EdTech teaching-assistant chatbot with FastAPI, React, REST APIs and WebSockets; architected a LangGraph StateGraph agent with structured-output routing and SQLite checkpointing for resumable multi-turn sessions.
    • Designed real-time hand-pose tracking across 21 landmarks for an iPad stroke-rehabilitation app using a confidence-gated TensorFlow Lite classifier with SwiftUI, AVFoundation, Apple Vision and AudioKit across 55+ MIDI-driven exercises.

04 — About

Short version

I spent three years at Cognizant on insurance systems where every payload carried PII and every release had a European operations team downstream of it. That is where I learned that the interesting engineering is usually in the constraints — regulated data, high volume, and no acceptable downtime window.

I am now a Research Assistant at Georgia State University, finishing an MS in Computer Science. The work has shifted toward applied ML that has to run somewhere small: a TensorFlow Lite classifier on an iPad that answers within the frame, MobileBERT semantic search inside a 4GB CPU-only budget, agents whose decisions are typed and checkpointed rather than hoped for.

The through-line is the same either way — build the thing so it holds up when it is not being watched.
